# Apex Dental Clinic AI Assistant
Customized by Foxy (Vyshu Sub-Agent) for Dr. Sarah Adams.

## Architecture
- **Type**: Web Chatbot
- **Template Source**: `gemini-ai-chatbot`
- **Hosting Tier**: 100% Free Tier (GitHub Pages + Gemini Free Quota)

## Files Included
- `config.json`: Clinic contact details, FAQ triggers, and brand colors.
- `app.js`: Lightweight JavaScript widget embeddable via a single `<script>` tag.
- `index.html`: Standalone demo preview of the chat widget.
